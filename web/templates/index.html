Sin intervención durante el aprovisionamiento.

  2. 2 Asigna hostname e IP fija Host-Only.
  3. 3 Configura el DNS interno en Bind9.
  4. 4 Publica HTML directamente o ejecuta la app con systemd + proxy.
  5. 5 Publica el enlace en este dashboard.
